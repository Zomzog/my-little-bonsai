# Spec Kit

Living design record for My Little Bonsai.

| Folder | Purpose |
|---|---|
| `specs/` | One file per feature. Created when a feature is planned or started. |
| `updates/` | One file per change to an existing spec. Named `YYYY-MM-DD-<slug>.md`. |
| `samples/` | Example data referenced by specs (e.g. the sample vault of [vault-format](specs/vault-format.md)). |

See [agents.md](../agents.md) for templates and rules.
